# 持股損益計算機（台股）

一個**打開網址就能用**的個人持股清單與損益計算工具。不用安裝任何東西、不用註冊帳號，資料自動存在你自己的瀏覽器裡。

---

## 一、怎麼用（30 秒上手）

1. 打開網址（或雙擊 `index.html`）
2. 在「新增持股」輸入 **股票代號**（例如 `2330`）→ 名稱會自動帶出
   - 代號支援英文字尾，如 `00632R`（元大台灣50反1）、`00637L`、`00878B`、`020000`
   - 大小寫不拘、全形數字也可以，會自動轉大寫並去除空白
   - 格式為「4~6 位數字，可帶 1 個英文字尾」；格式不對會提示「代號格式不對，請輸入像 2330 或 00632R 這樣的代號」
3. 填 **股數**（1 張 = 1000 股）和 **買進均價** → 按「加入持股」
4. 上方總覽卡立刻顯示總市值、總成本、總損益、總報酬率

> 第一次打開會有一筆台積電的示範資料，直接按「刪除」就能清掉。

### 現價怎麼來？兩種模式

| 模式 | 怎麼做 | 說明 |
|---|---|---|
| **模式一（預設，一定可用）** | 直接在「現價」欄位手動輸入 | 完全離線、不會有任何假數字 |
| **模式二（選填）** | 到「費用設定」填入即時報價代理網址 | 每 30 秒自動抓現價；抓不到會顯示「未連線代理，請手動輸入」 |

**為什麼需要代理？** 瀏覽器直接抓證交所 MIS 會被 CORS 擋住（證交所沒開放跨網域）。所以純靜態網頁拿不到即時報價，必須靠一個小後端代抓。若你有先前的路線 B 代理（FastAPI，端點 `/api/quote?codes=2330,2317`），填進去就能自動更新。

## 二、費用公式與預設值

### 手續費

```
手續費 = 成交金額 × 0.1425% × (折扣 ÷ 10)
若 手續費 < 最低手續費(20元) 且 成交金額 > 0 → 以 20 元計
```

- 買進、賣出**各收一次**
- 折扣可分別設定（6 折填 `6`、2.8 折填 `2.8`、不打折填 `10`）
- **零股同樣適用最低 20 元**（這點常被忽略：買 100 股 @1000 元，手續費 85.5 元 > 20 元，不觸發；但買 10 股 @50 元，手續費 0.71 元 → 收 20 元）

### 證交稅（只有賣出時收）

| 標的類型 | 判定方式 | 預設稅率 |
|---|---|---|
| 一般股票 | 其他 | 0.3% |
| ETF | 代號 `00` 開頭 | 0.1% |
| ETN | 代號 `02` 開頭 | 0.1% |
| 債券 ETF | 代號 `00xxxB`（B 結尾） | 0% |
| 現股當沖 | 該筆勾選「當沖」且設定開啟減半 | 稅率 ÷ 2（0.3% → 0.15%） |

每筆都可以用「證交稅率覆蓋」手動指定，蓋過自動判斷。

### 其他選填項目

| 項目 | 說明 |
|---|---|
| 融資利息 | 你算好後填入總額，有填才算 |
| 融券手續費＋借券費 | 同上 |
| 其他費用 | 自由填寫 |
| 手續費折讓／回饋 | 會從總成本扣除 |
| 匯費／轉帳費 | 每筆賣出固定扣除（設定區） |

### 損益公式

```
總成本   = 股數 × 均價 + 買進手續費 + 融資利息 + 融券費 + 其他 − 折讓
市值     = 股數 × 現價
淨損益   = 市值 − 賣出手續費 − 證交稅 − 匯費 − 總成本
報酬率   = 淨損益 ÷ 總成本 × 100%
```

**注意**：淨損益是「**假設用現價賣掉**」的結果，所以已經扣掉賣出手續費與證交稅。總覽卡另外顯示「毛損益」（未扣賣出費用）讓你對照。

## 三、本工具「沒有」計入的費用

我不假裝算得很精準。以下項目**不會**出現在損益數字裡：

1. **券商系統使用費／帳管費** — 部分券商每月 50～100 元，與交易筆數無關，無法按單筆分攤
2. **借券費用的浮動計息** — 按日計息、費率隨標的變動，只接受手動填入的固定金額
3. **融資利息的實際計息天數** — 實際按交割日到還款日計算，只接受你算好的總額
4. **匯率與海外所得** — 複委託、海外 ETF 完全不處理
5. **股利所得的年度申報調整** — 除權息區塊只是概算，8.5% 可抵減上限 8 萬元等需年度申報
6. **手續費折讓的實際入帳時間** — 多數券商月結退還，只在你填「折讓」時才扣
7. **零股與盤後定價交易的議價差異** — 一律用同一組設定
8. **當沖的沖銷稅認定** — 只依你勾選的「當沖」標記套用

## 四、資料保存與備份

- 資料存在瀏覽器的 **localStorage**，關掉再開還在
- **不會上傳到任何伺服器**
- 換裝置、換瀏覽器、清除瀏覽器資料 → 資料會消失

**所以請定期備份**：
- 按「**匯出**」→ 下載 `holdings-YYYY-MM-DD.json`
- 新裝置按「**匯入**」→ 選那個檔案（可選「合併」或「覆蓋」）
- 也支援匯入 CSV，欄位：`股票代號,股票名稱,股數,買進均價,現價,買進日期`

## 五、放到 GitHub Pages（5 步，全程網頁點選）

1. 登入 GitHub → 右上角 `+` → **New repository** → 名稱填 `my-holdings` → 選 **Public** → Create
2. 進入 repo → **Add file** → **Upload files** → 把 `index.html` 和 `README.md` 拖進去 → **Commit changes**
3. 上方 **Settings** → 左側 **Pages**
4. **Source** 選 `Deploy from a branch`，Branch 選 **main**、資料夾選 **/ (root)** → **Save**
5. 等 1～2 分鐘，重新整理這一頁，上方會出現網址：`https://你的帳號.github.io/my-holdings/`

> 手機可以把這個網址「加到主畫面」，用起來就像 App。

## 七、常見問題

**Q：為什麼現價欄位留空，損益還是算得出來？**
A：留空時會用「買進均價」當現價，所以損益是 0。填了現價才會出現真實損益。

**Q：手續費怎麼跟我的券商算的不一樣？**
A：先確認「費用設定」裡的折扣。預設是 6 折，若你是 2.8 折要改成 `2.8`。另外最低手續費 20 元若你的券商有不同規定，也可以改。

**Q：ETF 稅率自動判斷錯了？**
A：在該筆的「證交稅率覆蓋」手動選正確的稅率即可。

**Q：代號欄位在手機上打不出英文？**
A：已修正。代號欄位現在是文字輸入（會自動轉大寫），手機上會跳出完整鍵盤；股數、均價、現價仍是數字鍵盤。

**Q：可以多人共用嗎？**
A：不行。這是純前端工具，每個人各自的瀏覽器有自己的資料。要共用需要後端資料庫。
